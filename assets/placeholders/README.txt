===================================================================
RECRUITMENT AGENCY - PLACEHOLDER ASSETS DIRECTORY
===================================================================

This project uses CSS-based placeholder containers for all media across
the website as per project specifications. No external image URLs or 
downloaded graphics are required.

The 8 unique placeholders implemented via CSS classes are:
1. recruitment-hero-placeholder       (Professional recruitment consultation / hiring discussion)
2. recruitment-team-placeholder       (Professional team collaboration)
3. candidate-interview-placeholder   (Interview or candidate evaluation scene)
4. employer-meeting-placeholder       (Business hiring consultation)
5. career-guidance-placeholder        (Career coaching or professional development)
6. resume-guidance-placeholder        (Resume and career planning workspace)
7. interview-preparation-placeholder  (Interview preparation scene)
8. office-environment-placeholder     (Modern professional office environment)

To replace any placeholder with a real photographic asset in the future,
replace the designated placeholder div container in the relevant HTML template
with a standard <img> element matching the specified aspect ratio.
